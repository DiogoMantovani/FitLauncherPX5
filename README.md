# Fit Launcher PX5

Launcher Android experimental independente, voltado à central Eonon GA2171SR/PX5 (Android 9, 1024×600) e ao Honda Fit 2010 preto.

O projeto será enviado nesta sequência com código Kotlin, testes e GitHub Actions para gerar APK debug. Não substitua o launcher original antes da validação.

**Estado:** protótipo em desenvolvimento. Sem firmware, sem root e sem escrita na ECU.
